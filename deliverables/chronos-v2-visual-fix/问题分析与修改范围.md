# 克洛诺斯 V2 视觉问题分析

## 原文件中能够确认的问题

1. TEST02 的 `preparePlayerFX` 把 `entEffectDesc.effect` 当作可直接赋 String 的字段，并在赋值后直接返回 true，没有原生字段读回校验。字段的真实类型是 `raRef<worldEffect>`。参考作者也使用 CET 的隐式转换，所以不能只凭写法断言转换一定失败；但 TEST02 的成功标记确实无法证明注册生效，`Registered FX 0` 与 START 可以同时出现。
2. TEST02 用 `tostring(p:GetEntityID())` 做身份键；该字符串变化就清理 prepared/stop，再 FALLBACK/start。反复 FALLBACK 的重置路径已定位。若 CET 返回的值包装字符串不稳定，会完整重现此症状；当前没有实机日志证明它就是此次唯一触发源，不能把推断冒充观察结果。
3. TEST02 要求 `ControllerIsActive && IsRunning`，前者是另一 CET 模块写入的每帧回显。视觉用已有严格 `IsRunning` 即可门控，不必增加模块执行顺序依赖。原 `IsRunning` 包含精确物品、PSM/native key、附着和存活检查。
4. TEST02 的说明要求旧 V2 `enabled.visual=false`，完整恢复包却是 true；叠加两包默认有两套视觉管理。旧视觉模块发现资源里任何 ColorGrade 就停止整个效果，所以如果同一原生资源也有扭曲，该扭曲会一起停止。
5. TEST02 依赖的 `chronos_vfx_probe.yaml` 不在三份附件中，无法核实其实际写法。其 README 明确承认全局影响其他 Sandy。完整包原有 `chronos_mk13.yaml` 本身没有去蓝全局覆盖。
6. 参考作者 Lua 全局改写 Sandy/Kerenzikov accepted reasons，并观察所有这些义体；不能照搬。其 archive 还覆盖原版主 depot 路径，即使不装 Lua 也不能据此保证其他义体完全不变。
7. 参考 archive 的径向模糊/轮廓等子资源不能简单当成游戏始终自带的独立效果。实际解码确认主 effect 是 `ColorGrade + neon_01.xbm`，子资源另有粒子引用。直接调用事件名不证明对应资源已注册、加载或可渲染。

补充取得的原版脚本时序证据：社区反编译仓库 [adamsmasher/cyberpunk 的固定 2.5 提交](https://codeberg.org/adamsmasher/cyberpunk/src/commit/17c62d000310f8938beb9593b3892c6c4febeffb/cyberpunk/player/player.swift) 中，`OnGameAttached` 第 1145 行先调用 `super.OnGameAttached()`，第 1203 行才注册 `PlayerAttachedCallback`；回调本身第 1054–1124 行没有 FX 初始化。PlayerSystem 的注册/派发声明是 native，无法从这份脚本证明内部缓存时机。因此 TEST02 的“必然在 FX 初始化前”说法没有依据。精确来源/文件哈希与边界见 `SOURCE_TIMING_EVIDENCE.json`，不把社区版本标记当作本机运行验证。

## 修复范围

- 本体核心、战斗 REDscript、属性 YAML 和所有非视觉 Lua 保持原字节。唯一原有配置变化：`MilitechChronosMK13V2/config.lua` 的 `enabled.visual` 由 true 变 false；tech/cooldowns 等均保持原值。
- 用一个新的 Lens 状态模块替代 TEST02，不再有第二套旧视觉管理同时启用。
- typed REDscript 明确构造 RARef，按期望 CName/hash 读回；同时 ObserveBefore/ObserveAfter 玩家附着回调。接口有 2.5 RTTI 依据，回调发生在引擎内部缓存构建前后仍不能凭签名保证。
- 使用本体 `ChronosBridge.SameOwner` 原生比较，不将 EntityID 字符串用于身份判断。
- 描述符/资源/请求/可见渲染四种状态分开；有限重试、边沿播放、错误锁定、明确停止原因。
- 所有自定义资源私有化为 `ch13\` 路径，别名以 `ch13_lens_` 开头，停止时只清理自有别名。原生颜色实例仅在精确克洛诺斯运行范围、确认含 grade 且私有播放请求成功后抑制；不修改缓存资源内容或全局 Tweak。
- 原版蓝色 LUT 主资源不分发。flash 私有副本仅将结构确认的青色 Color 参数变为中性灰，保留原时间/曲线/扭曲强度。资源格式和校验依据见源码包中的 `resources/RESOURCE_ANALYSIS.md`。

## 不在当前环境中声称完成的事项

- 实际 REDscript 编译、CET/引擎字段互通。
- 玩家 FX 内部 lookup 对动态描述符的更新。
- 本地游戏资源依赖的加载、shader 的实际色彩含义、GPU 渲染。
- 连续扭曲场、所有义体组合/加载切换场景的完整回归。

因此交付是完成了静态资源重建与代码修复的**待实机验证版本**，不能称为已在用户机器上修好。遇到 `registered=3`、`privateLoaded=3/3`、`requested=true` 而画面仍无效果时，应继续定位原生 lookup/资源依赖/效果上下文，而不是继续每帧重复 Start。
